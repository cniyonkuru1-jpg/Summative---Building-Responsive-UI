# My Fincance Tracker
 A responsive web app for recording spending and setting monthy budget. it saves data in your browser with local storage.

## Features

-Add and delete transactions
-view spending totals and top category 
-set monthly budget caps and track what remains
-navigate between sections
-keyboard accessible and mobile friendly 

## Run 
open `index.htm` in a browser
